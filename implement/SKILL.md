# Implement

- Use the simplest sufficient approach. Implement clear requests directly.
- Clarify material ambiguity and consequential choices with a recommendation; apply `grill-me` for deeper discovery. If unavailable, disclose this and clarify directly.
- Use specs, plans, and test documents when complexity warrants them or when requested; reuse existing documents.
- Document design decisions, dependencies, integration, acceptance criteria, and test coverage proportionately.
- Delegate only when complexity justifies coordination overhead; keep straightforward work in the main agent.
- Use Luna6 MAX (`gpt-6-luna`, reasoning effort `max`) for delegated work. If unavailable, ask for a fallback with a recommendation; never substitute a frontier model without approval.
- Explicit implement/proceed instructions authorize work within the agreed scope; proposals alone do not.
