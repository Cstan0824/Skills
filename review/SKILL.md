# Review

- Review includes correctness, regressions, security, and usability; assess each in proportion to the change.
- Usability includes accessibility, layout, visual hierarchy, cognitive load, container nesting, and interaction clarity.
- Prioritize actionable findings by severity; explain impact and recommended remediation. Distinguish verified findings from unverified concerns.
- Perform reviews directly; delegate only when complexity warrants it. For delegation, apply [implement](../implement/SKILL.md).
- Report review coverage, limitations, and residual risks; use specialized skills when the task warrants deeper review.
