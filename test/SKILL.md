# Test

- Test includes build verification, functional tests, and regression checks.
- Use executable unit/integration tests as appropriate; cover positive, negative, and edge cases.
- Choose checks relevant to the affected behavior and risk; reuse existing tests where sufficient.
- Record actual results; distinguish passed, failed, blocked, skipped, and unrun checks. Disclose unavailable checks and coverage gaps.
- A passing build alone does not establish functional correctness.
